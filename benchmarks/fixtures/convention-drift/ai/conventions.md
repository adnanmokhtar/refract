# Conventions — Acme Orders

The team's rules. Everything outside the generated block near the end was written and reviewed by
people; each rule names the tool that enforces it where one does. An exception needs an ADR or a
ticket id on the suppression itself (`-- ADR-0007`, `-- ORD-412`).

## Imports and wrappers

- HTTP from browser code goes through `@acme/http` (`apiClient`). Never import `ky` or `axios` in
  `apps/` or `packages/` outside `packages/http`. Enforced by `no-restricted-imports`.
- Radix primitives are wrapped by `@acme/ui`. Feature code never imports `@radix-ui/*`.
- Dates and money are formatted through `@acme/format`. Feature code never imports `dayjs`, and
  `moment` is banned everywhere.
- Shared helpers are imported, never copied: `formatMoney` and `formatDate` from `@acme/format`,
  `useDebounce` from `@acme/ui`.
- A workspace package is imported through its entry point only (`@acme/ui`, `@acme/http`). Never
  reach into another package's `src/`, `dist/` or `internal/`.
- The reports service calls HTTP through `app.http_client` only; `requests` is banned (Ruff TID251).

## Layering

- Components never import `@acme/http`. A component gets server data through a hook: the
  feature's `use*.ts` or `apps/web/src/hooks/`.
- Code under `apps/web/src/server/` runs at build and prerender time and may call `fetch`
  directly; the `@acme/http` rule covers browser code.
- In `apps/api`, controllers call services; only services import a `*.repository.ts`.

## State

- `apps/admin` state uses pinia only. No other store library in admin, framework-free ones
  included.
- Pinia store files end in `.store.ts` (`orders.store.ts`).
- react-redux `connect()` is retired. Components read the cart store through `useAppSelector` and
  `useAppDispatch`; the last `connect()` callers were due to move by 2026-06-30.

## Components and permissions

- `<DataTable>` defaults `canDelete` to `true`. A read-only page passes `canDelete={false}`.
- A destructive action is rendered inside `<Can action="…">` from `@acme/ui`. Never render a delete
  or refund control ungated.
- `<IconButton>` always gets a `label`; it becomes the accessible name.
- In `apps/web`, use the `@acme/ui` `Button` for every button; a native `<button>` belongs only
  inside the wrapper's own implementation.

## Naming

- Component files under `apps/web/src/` are PascalCase and match the exported component
  (`OrderRow.tsx` exports `OrderRow`).
- Feature directories under `apps/web/src/features/` are kebab-case (`order-history/`).
- TypeScript variables, functions and properties are camelCase (module-level constants may be
  UPPER_SNAKE_CASE); type and class names are PascalCase.
- Boolean props and variables start with `is`, `has`, `should` or `can` (`isLoading`, not
  `loading`). Enforced by `@typescript-eslint/naming-convention`.
- Python functions are snake_case (Ruff `N802`).
- Domain words come from `ai/glossary.md`; never use a listed synonym in identifiers, routes,
  translation keys or event names.

## Layout

- Tests are co-located: `OrderRow.test.tsx` beside `OrderRow.tsx`. No `__tests__/` directories.
- Each feature under `apps/web/src/features/<name>/` exposes an `index.ts` barrel; other features
  import the barrel only.

## Design tokens

- Never hardcode a colour, spacing or font-size value in app CSS or inline styles; use the
  `--color-*`, `--space-*` and `--font-size-*` tokens from `@acme/ui/tokens.css`.
- Admin styles come from the Tailwind theme in `apps/admin/src/styles/theme.css`; never an
  arbitrary value such as `bg-[#2563eb]`.
- Chart series colours come from `apps/web/src/charts/palette.ts`, the categorical palette; they
  are not UI tokens.
- E-mail templates under `apps/web/emails/` inline their colours; mail clients drop CSS variables.

## Styling

- New and touched web components use CSS Modules (ADR-0011). styled-components is being removed
  from `apps/web`; `packages/legacy-reports` is frozen (ADR-0009).

## i18n

- Every user-visible string goes through `t()` from `@acme/i18n`. Reuse an existing key when the
  copy is identical (`common.save`).

## API

- All endpoints live under `/api/v1`.
- Errors are RFC 9457 problem details (ADR-0004).
