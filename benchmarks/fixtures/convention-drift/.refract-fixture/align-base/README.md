# Ratchet base copies (fixture infrastructure)

The staged copy has one commit, so `git diff <base> -- <baseline file>` has nothing to compare.
These are the baseline files as they stood on the base branch, at their repo-relative names under
this directory. `convention-ratchet-scan` §2 (AL-30) reads them as `--base-dir`. They are not
project code and carry no conventions of their own.
