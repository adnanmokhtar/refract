# Tallyhook

Tallyhook is an invoicing API for online merchants. These pages explain how to run it, how
billing works and how to integrate with it.

- [Getting started](setup.md): run the API on your machine.
- [Billing](billing.md): how invoices are numbered and sent.
- [SDK](sdk.md): the TypeScript client.
- [Webhooks](webhooks.md): signed event deliveries.
- [Reports](reports.md): monthly totals and backfills.
- [FAQ](faq.md): currencies, invoice numbers and limits.
