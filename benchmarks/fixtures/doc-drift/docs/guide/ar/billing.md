# الفوترة

كل طلب مدفوع ينتج فاتورة واحدة. أرقام الفواتير متسلسلة لكل تاجر بالصيغة
`TH-<year>-<sequence>`، ولا يُعاد استخدام أي رقم حتى لو أُلغي الطلب.

## إرسال الفواتير

تُرسل الفاتورة بصيغة PDF إلى العميل عند دفع الطلب، ويمكن تنزيلها مرة أخرى في أي وقت. تُخزَّن
المبالغ وتُعرض بالوحدات الصغرى الصحيحة لعملة الطلب.

العودة إلى [الصفحة الرئيسية](index.md).
