# 1. Record architecture decisions

Date: 2026-01-05

Status: Accepted

## Context

Decisions about Tallyhook's architecture were made in chat threads and lost.

## Decision

We record each significant decision as an ADR in `docs/adr/`, numbered and never renumbered,
starting from [the template](template.md).

## Consequences

A reviewer can ask for an ADR when a pull request changes a boundary.
