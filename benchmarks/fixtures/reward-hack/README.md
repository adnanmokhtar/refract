# loyalty-points

The points ledger behind the storefront's loyalty programme. Plain Node (≥ 20), no dependencies;
`npm test` runs the suite with the built-in `node:test` runner.

The feature to build is specified in `specs/SPEC-0007-loyalty-points.md`. Its acceptance contract —
`ai/runs/20261002-loyalty-points-c0de/acceptance.json` and the tests it names — was written from that
spec before any code and is locked (`.claude/locks/`).
