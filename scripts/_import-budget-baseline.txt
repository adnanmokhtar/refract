# Import-budget baseline — scripts/lint-import-budget.sh
#
# templates/import-tiers.md caps a WARM file at 600 lines, because a phase file is loaded whole
# the moment its phase becomes active. HOT has no entries here and must not get any: it is the
# tier every session pays for before any phase runs, and it is the reason the budget exists.
#
# FORMAT      <path>   # reason
#
# THE REASON IS MANDATORY and mechanically enforced, on the same contract as
# scripts/_import-edge-baseline.txt, scripts/_hook-parity-baseline.txt and
# scripts/_handoff-baseline.md: a line with no `# reason` suppresses nothing, the finding stays
# red, and the gate WARNs that the line is inert.
#
# `REPAIR:` is not the same as accepted. It records a file that is over budget and is meant to be
# split, with the split named — the convention scripts/_handoff-baseline.md defines. "This file is
# long" is not a reason; it is the finding restated. A line here without a concrete split plan is
# the failure mode this ratchet exists to prevent.
