# /test-audit

## What this does

Read-only test-suite audit: every testing detector on a whole repo, by signal on a diff; each candidate refuted before it counts; a fixed class ledger and a GO / GO-UNVERIFIED / NO-GO verdict. /test-fix closes the findings.
