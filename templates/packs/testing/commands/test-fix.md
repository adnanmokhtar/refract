# /test-fix

## What this does

Close the findings a /test-audit report lists: prove each failing-first with its testing oracle, fix the test not the code, check the fix's own diff for tampering, re-detect, sweep siblings, run the whole suite shuffled. Stops on a spec-test conflict.
