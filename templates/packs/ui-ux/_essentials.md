# Ui-ux — essentials manifest

Files listed above are the minimal subset copied when `/setup-project --minimal` is used. Standard mode copies the entire pack; minimal mode copies only essentials.

Rationale per category (one line each):
- agents: design-system-architect designs, ux-reviewer audits — the minimum design+review pair; design-system-guardian and theme-specialist are specialists kept out of minimal. creative-director (v1.5+) — the upstream creative high-ground that SETS and INVENTS the visual direction from product goals (concept, original visual language, signature moments) before the architect codifies it — is a strategic specialist kept out of minimal; it ships in standard mode.
- commands: design-review is the read-only audit; enhance-ui is the orchestrator command for full UI/UX enhancement (cleanup → iterate → re-enforce). redesign is the from-scratch rework command — it rethinks a page's layout + UX (NOT a restyle) and rebuilds it inside the existing design system, with a mandatory approval gate before any code; sibling to enhance-ui (which preserves structure). art-direct (v1.5+) — the one command UPSTREAM of redesign that decides + invents the visual language itself (evolve / reimagine modes, gated brief, hands off to design-system-architect → redesign → polish) — is kept out of minimal as a strategic specialist; standard mode only. ui-crawl + ui-crawl-fix (the Playwright cross-route crawler + auto-fix loop, v1.2+) are kept out of minimal because they require Playwright + axe install plus a `tests/crawl/` scaffold; they ship in standard mode. add-theme-variant (v1.17+) — ADDS a new theme slot to a **multi-theme** app (never edits an existing theme or the shared layer), built modern + technically-correct + fast + feature-complete-vs-the-default-theme, each aspect gated (additive/architecture/parity/perf/visual); executed by `theme-specialist`. Multi-theme architectures only (a `themes/<name>/` slot system) — single-theme projects are redirected to `/art-direct`/`/redesign`. Kept out of minimal (niche specialist); standard mode only. clone-design (v1.18+) — clones an **external** design reference (a live URL or a screenshot) into a self-contained folder of framework-neutral HTML/CSS: every page template + a reusable section library, styled to a token system EXTRACTED from the reference, then VERIFIED by rendering each built page and pixel-diffing it against the reference (Stage 1); Stage 2 adoption (`--adopt`) delegates into `/add-theme-variant` (tokens) / `/redesign` (pages) / a platform-theme emitter. The one command whose source of truth is OUTSIDE the repo (fidelity to a reference, measured from pixels) and the one that is project-optional + stack-agnostic (Stage 1 needs no framework/idioms/repo). Reproduces the design LANGUAGE, placeholders the brand IDENTITY (not a counterfeit). Kept out of minimal (specialist); standard mode only. grab-site (v1.19+) — the faithful-grab SIBLING to clone-design: FAITHFULLY MIRRORS a live site (real HTML/CSS/images/fonts, one page per template family, links rewritten to open offline) so the output looks like the ORIGINAL, not a placeholdered wireframe. Runs a bundled stdlib-Python mirror script (only `python3`; no wget/httrack). Use grab-site for "same design as this site"; use clone-design for a brand-neutral design *system*. Carries the source's real content — swap your own brand in before shipping. Stack-agnostic + project-optional. Kept out of minimal (specialist); standard mode only.
- skills: ui-design-sweep is the closed 19-verb closure-vocabulary the frontend half of /polish + /ui-sweep + /enhance-ui dispatch; design-token-audit / motion-audit / a11y-quick-check are short detector audits; design-iterate generates 3 visual variants for /enhance-ui to dispatch.
- rules: ui-principles is the single rules file in the pack.
- ai-patterns: axis-catalog is essential — it holds the per-axis heuristics for the closed 16-axis / 19-verb vocabulary that ui-design-sweep (a minimal-mode skill) closes against and that ux-reviewer scores from; ui-principles.md carries only the closed axis NAMES so the always-loaded rule stays small. dark-mode/motion/rtl/theming/design-systems are project-specific decisions (full set ships in standard mode).
