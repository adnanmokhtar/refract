# mobile-lifecycle-scan

Find lifecycle defects in RN/Expo, Flutter, iOS and Android apps — state lost on process death, background and FGS limits, permission dead ends, network calls with no timeout, deep-link payload crashes, push token and cold-start tap routing, OTA runtime mismatch — each proved on a device.
