# 3. Postgres as the primary store

Status: Accepted
Supersedes: ADR-0002
Date: 2026-05-25

## Context

Tenancy filters and the monthly reports need partial indexes and JSONB.

## Decision

Postgres 16 through MikroORM's `@mikro-orm/postgresql` driver, one database per environment.

## Consequences

Migrations are generated by MikroORM and reviewed before merge.
